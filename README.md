**Админ:** Сиз  
**Телефон / MBank төлөм:** 0556-652-652

## Мүмкүнчүлүктөр
- Өтө так GPS (enableHighAccuracy)
- OpenStreetMap картасы
- Үзгүлтүксүз көзөмөлдөө (watchPosition)
- Координаттарды көчүрүү
- Шилтеме аркылуу бөлүшүү
- PWA (телефонго орнотууга болот)
- Админ панел

## Иштетүү
1. GitHub Pages күйгүзүңүз (Settings → Pages → main branch)
2. Же Acode менен ачып, Live Server менен иштетиңиз

## Маанилүү
Бул тиркеме **consent-based** (өзүнүн жерин бөлүшүү).  
Башка адамдарды уруксатсыз көзөмөлдөө мыйзамга каршы жана бул коддо жок.

## Технологиялар
- Vanilla HTML / CSS / JS
- Leaflet.js + OpenStreetMap
- Service Worker (PWA)
